# UI UX Pro Max sub-skills and sample stack

Source: `ui-ux-pro-max` — `design/`, `ui-styling/`, `design-system/`, `brand/`, `slides/`,
`banner-design/`, `stack/`.

## Decision

Not curated. The markdown guidance is (`uiux.guidelines`); the full toolkit is a
`native_plugin` hint (`uiux.full-toolkit`).

## Why

They call Gemini, Pexels and other external APIs, run `subprocess` and Node scripts.
`ui-styling` is Apache-2.0 with OFL fonts. `stack/` is a sample project whose `.mcp.json`
launches Playwright and chrome-devtools via `npx -y`.
