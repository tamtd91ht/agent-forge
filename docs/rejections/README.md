# Rejected and deferred upstream content

One file per rejected (or deferred) item, so the reason survives and a scout or curator can
check it before proposing the same thing again. Read these before adding a source or a
capability; the `agent-forge-scout` skill does.

Each file has: the source and paths, **Decision**, **Why** (the invariant or licence that
blocks it), and optionally **Revisit when** (what would have to change).

To add one: create `<source-id>-<item>.md` here and add it to the list below. Items that are
merely interesting but not ready are listed under *Watching* in
